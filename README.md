# 55 Bar y Cocina — Valdivia

Demo web de prospección para **55 Bar y Cocina** (Los Robles #55, Valdivia).
Diseño y desarrollo: [NVY Studios](https://nvystudioss.vercel.app).

- Página única en HTML + CSS puro (sin frameworks).
- Carta completa (428 ítems) extraída del sistema Fudo del local, con fotos reales.
- Estética iOS / liquid-glass con paleta cálida costera.

## Deploy
Sitio estático. Se despliega tal cual en Vercel, Netlify o cualquier hosting estático.
`index.html` + carpeta `assets/` deben mantenerse juntos.
